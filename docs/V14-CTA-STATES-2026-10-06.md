# V14 stop — CTA states (hover, pressed, focus, disabled)

*2026-10-06. Base: commit `3ff9d64` (CTA swap). Spec: DESIGN-TOKENS-v14.md § Primary CTA button.*

| State | Light surfaces | Dark surfaces |
|---|---|---|
| Rest | acid fill, black text (unchanged) | acid fill, black text (unchanged) |
| Hover | **lime** fill, black text | **lime** fill |
| Active / pressed | acid fill, black text | acid fill, black text |
| Focus (keyboard) | 2px **olive** ring, offset 2px | 2px **lime** ring, offset 2px |
| Disabled | step 4 fill (`#909097`), step 6 text | step 5 fill (`#5e5e64`), step 3 text |

## What changed (30 rule edits across 25 files)

**Light-surface CTAs** (hover was an olive fill with white text, or an off-palette `#8bc400`; no active/focus/disabled): `about-this-project.html .btn-lime-about` · `bluesky-creator-intelligence.html .header-cta` · `index.html .btn-lime`, `.btn-lime-lg` · `research.html .btn-lime` · `for-brands.html .form-submit` · `assets/css/main.css .clear-filters-top` (search page) · `updates.html .submit-btn` (had a 60%-opacity disabled and a scale-on-press; now v14 states, press keeps its scale).

**Dark-surface CTAs** (hover was already lime on most; the rest got focus/active/disabled): `contact.html .contact-email-btn` (hover was off-palette `#d4ff33`) · `research.html .btn-acid` (hover was `#d8ff33`) · `for-brands.html .btn-primary`, `.bf-submit` · `index.html .btn-acid` · `submit.html .updates-cta-btn` · `latin-america-lab.html .btn-primary` (its existing focus ring was acid; now lime, and the same rule covers its ghost/pill/card-link/spotlight focus rings) · **14 partner footer buttons** (`.atlas-footer-btn`): hover was `opacity: .88`, now lime; focus ring was olive-on-dark, now lime.

**The header search button** (`header.css`, on every page): it rested at hardcoded lime `#97d600`, so it was the one CTA the swap had missed. Now acid at rest, lime hover with black text, acid pressed, olive focus ring, v14 disabled. Hardcoded hex with `var()` fallbacks because 12 pages load `header.css` without the variables. **This is a visible change on every page header.** It can be reverted on its own: it is the only change in `header.css`.

Edits sit next to each CTA's existing rule (hover edited in place; active, focus-visible and disabled added directly after it). Disabled uses `:disabled` and `[aria-disabled="true"]`, so links can use it.

## Verification

1. **Regression, whole site.** Committed tree vs. working tree on 58 pages: 5,477 → 5,758 resolved CSS rules, 144,761 rendered elements. **511 rule differences on 47 pages, every one in a rule whose selector is one of the CTAs above; the only rendered-at-rest change is the header search button, lime → acid, 47 pages. 0 unexpected.**
2. **Real-browser states.** For 20 CTAs (every selector above on a representative page) a browser hovered, pressed, keyboard-focused (`:focus-visible`) and disabled each and compared the computed colors to the table: **20 of 20 match** (hover fill/text, pressed fill/text, ring color, 2px width and 2px offset, disabled fill/text/cursor). One miss on the first run (`.form-submit` hover kept `#111111` text) was fixed.
3. Not covered: colors set in JavaScript, `a` elements that script marks disabled in some other way, and touch devices.
