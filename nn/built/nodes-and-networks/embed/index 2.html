Nodes and Networks

Embed the explorer

Paste one of these into your page. The address ends in ?embed=1, which removes the header and footer and makes the background clear.

The explorer can be framed on asu.edu pages and on journalismatlas.com. To use it on another site, ask us first.

Size

Use a width of 760px or less. The explorer fills the width you give it. Height depends on the tab and the width. A fixed frame needs 1900px under 760px wide and 1500px from 760px up, which fits every tab and leaves empty space on the shorter ones. The auto-height code below has no empty space.

1. Plain iframe

Works in any system that allows iframes.

<iframe
  src="https://journalismatlas.com/nodes-and-networks/explorer/?embed=1&tab=short"
  title="Nodes and Networks explorer: 169 U.S. journalism organizations"
  loading="lazy"
  style="display:block;width:100%;max-width:760px;height:1900px;margin:0 auto;border:0"></iframe>

2. Plain iframe with two heights

If your system allows a style block, this switches the height at 760px.

<style>.nn-frame{display:block;width:100%;max-width:760px;height:1900px;margin:0 auto;border:0}
@media (min-width:760px){.nn-frame{height:1500px}}</style>
<iframe class="nn-frame" src="https://journalismatlas.com/nodes-and-networks/explorer/?embed=1&tab=short" title="Nodes and Networks explorer: 169 U.S. journalism organizations" loading="lazy"></iframe>

3. Auto-height iframe

If your system allows scripts, this resizes the frame to fit. There is no empty space and no inner scrollbar. The explorer sends its height each time its size changes, and the listener accepts messages only from this frame. To embed two explorers on one page, copy the code and change the id.

<iframe id="nn-explorer" src="https://journalismatlas.com/nodes-and-networks/explorer/?embed=1&tab=short"
  title="Nodes and Networks explorer: 169 U.S. journalism organizations" loading="lazy"
  style="display:block;width:100%;max-width:760px;height:1900px;margin:0 auto;border:0"></iframe>
<script>
addEventListener('message', function (e) {
  var d = e.data, f = document.getElementById('nn-explorer');
  if (!d || d.source !== 'nn-explorer' || d.type !== 'height' || e.source !== f.contentWindow) return;
  f.style.height = d.height + 'px';
});
</script>

A still of the first chapter, linked to the live explorer. Upload the image to your media library and change the image address to match.

Good to know

  • Tabs work with the keyboard. Arrow keys move between them.
  • With "reduce motion" on, tabs switch with no animation.
  • The explorer follows the visitor's light or dark setting. The chart area is always black.
  • Hover or tap a mark to see the organization, its kind of newsroom, how it grew, its revenue and the year it was founded.
  • No cookies, no network requests, no outside fonts or scripts. The explorer is one self-contained page.
